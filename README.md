# Auravector-DB-SynaptiX
AuraVector DB: High-precision, low-latency hybrid vector engine for RAG systems. Combines BGE dense embeddings, Rank-BM25, Reciprocal Rank Fusion (RRF), Cross-Encoder reranking, and SVD entropy analysis to eliminate LLM hallucinations under a $p95 &lt; 300\text{ ms}$ constraint. Built for ADROSONIC Build Challenge by Team SynaptiX (BIT Mesra).
